# Creature Atlas

A responsive Pokémon field guide built with semantic HTML, CSS, and the browser
Fetch API. Search by Pokémon name or Pokédex number, or choose **Surprise me**
to discover one at random.

The app gets Pokémon data from the public, key-free
[PokéAPI](https://pokeapi.co/). Open `index.html` in a browser to use it; an
internet connection is needed to load creature data and artwork.
